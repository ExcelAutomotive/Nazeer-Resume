# Nazeer Ahmed — Automotive Service Technician Resume

A modern, responsive static resume website designed for free hosting with **GitHub Pages**.

## Files

- `index.html` — resume content and structure
- `style.css` — responsive design
- `script.js` — mobile navigation and current year

## Publish on GitHub Pages

1. Create a new GitHub repository, for example `nazeer-ahmed-resume`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide the public Pages address.

## Personalize

The current page uses the information supplied in the reference letters. Before publishing publicly, review the phone numbers and any other contact information you want visible online.

The design uses Google Fonts from Google Fonts CDN. The site otherwise uses only HTML/CSS/JavaScript and does not require a backend.
